# College Tracker

v1: local-only dashboard for tracking assignments and exams. No accounts, no
integrations yet — see [PRD.md](./PRD.md) for the full roadmap.

## Run it

```
npm install
npm run dev
```

Then open the URL it prints (usually http://localhost:5173).

Data is stored in your browser's localStorage — nothing leaves your machine.

## Stack

React + Vite, plain CSS, localStorage for persistence.
